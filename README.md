The Gesture-Driven AI File Viewer is an innovative desktop application that combines computer vision, speech recognition, and artificial intelligence to provide a completely hands-free file viewing experience. This project allows users to control and navigate files through simple hand gestures and voice commands, offering a modern, AI-assisted approach to file management. It is built using Python with CustomTkinter for the user interface, MediaPipe for gesture tracking, Vosk for offline voice recognition, and Hugging Face API for intelligent text and command processing.

The application’s main purpose is to create a smarter and more interactive way of handling files, especially useful for situations where physical contact with the computer is inconvenient. Users can open, close, and switch files using gestures, or give commands like “open image”, “read file”, and “summarize text” through their voice. The integration with Hugging Face’s AI models enhances the system’s ability to understand natural language and perform advanced text-based operations like summarization and content interpretation.

The project features a clean and responsive dark-themed UI built with CustomTkinter, offering a modern and user-friendly interface. It also supports multiple file formats such as PDFs, text files, and images. With offline speech recognition powered by Vosk, users can continue using the app even without an internet connection.

To run the application, users must install all required Python libraries, download and extract the Vosk model for offline recognition, and generate their Hugging Face API token for AI-based processing. Once configured, the application can be executed with a simple python main.py command. The system automatically detects gestures and listens for commands, responding instantly with visual or audio feedback.

This project demonstrates a practical implementation of AI in real-world scenarios, especially in human-computer interaction and accessibility domains. It can be extended further to include optical character recognition (OCR) for image-based text extraction, multilingual command support, cloud file integration, and customizable gestures. The Gesture-Driven AI File Viewer represents a creative step towards intelligent, contactless computing experiences.
